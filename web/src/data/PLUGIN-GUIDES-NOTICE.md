# Apache APISIX plugin documentation

The overviews, field descriptions and example titles in `plugin-guides.json` and `plugin-guides.en.json` are extracted from the Chinese and English editions of the Apache APISIX documentation, distributed under the Apache License, Version 2.0. The Dashboard selects help by plugin, field and configuration scope. It uses the connected gateway's schema for validation.
