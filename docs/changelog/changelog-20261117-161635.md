# Changelog 20261117-161635

## 本次变更摘要

V1.0.2 将消费者的访问权限细化到路由、服务和单种内联认证。完整操作说明、兼容条件及升级命令见[版本说明](../releases/V1.0.2.md)。

### 功能与实现

- 消费者列表展示认证访问范围。消费者表单可搜索、多选允许的路由或服务。已有路由和服务的认证插件窗口可直接为当前资源签发凭据。中英文界面共用同一组配置和校验规则。
- 服务端新增单种内联凭据授权接口和插件能力字段。迁移复用已有密钥、消费者组和其他非认证策略，按集群权限提交或发布，产生可审计的脱敏记录。
- 回退按成功操作的逆序执行，先释放新身份的凭据，再恢复原身份。新用户名可能影响上游鉴权和按身份计数的规则，迁移期间可能短暂返回 401。
- README 更新安装版本、升级步骤和两张实测截图。管理 API 和消费者插件验收文档补充接口字段、适用条件及逐插件结果。

### 验证

- 107 项前端单测、格式检查、TypeScript 和 Vite 生产构建通过。Go 竞态测试及静态检查通过。使用新版本清单在本地重建 Dashboard 后，健康检查返回 HTTP 200。
- 针对 APISIX 3.19.0 的 17 项浏览器回归全部通过。七种认证逐项验证名单内放行、越界拒绝和回退。另验证 JWE 与身份认证组合、LDAP 身份绑定开关、独立 Credential、权限、脱敏及高级策略。Wolf 外部服务使用本地协议测试端。[验收记录](../consumer-plugin-verification.md#2026-11-17-消费者访问范围验收)
