# V1.0.1 开发变更记录

## 本次变更摘要

本次记录对应 [APISIX Dashboard Next V1.0.1 版本说明](../releases/V1.0.1.md)，比较基线为 V1.0.0。

- 发布与迁移：统一直接发布、提交待审及回退，保留历史草稿和审计。
- 配置界面：完善路由操作和 OpenAPI 工具、服务上游表单、插件字段帮助和中英文操作。
- 运行维护：增加集群删除与后台健康探测，修复配套 3.19.0 网关多 worker 的故障节点摘除。
- 配置接口、部署方式、截图和验证覆盖范围以版本说明和 README 为准。
